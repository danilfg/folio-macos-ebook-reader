# Security policy

## Supported version

Security fixes are applied to the latest release line.

## Reporting a vulnerability

Please do **not** publish a security vulnerability as a normal GitHub issue. Use GitHub's private vulnerability reporting / Security Advisory feature when it is enabled for the repository.

Include the affected Lexumi version, macOS version, document format, reproduction steps and a minimal non-sensitive sample if one is required.

Lexumi processes untrusted local document files through MuPDF and DjVuLibre. Keep dependencies updated and avoid opening suspicious documents from unknown sources.
